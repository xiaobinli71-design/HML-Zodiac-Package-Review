## 4. 系统级整改方案（R-01 ~ R-09）

### R-01 刀版尺寸双轴契约（P0）
- **契约**：`standard_dieline.out_extent_mm` 必须同时满足 `|ΔL| ≤ 1mm` **且** `|ΔW| ≤ 1mm`；"W 为派生值"不得作为交付口径。
- **现状**：pipeline L1529 只校验 L；`standard_geometry` 在比例不匹配时静默派生。
- **改动点**：①L1529 增加 W 校验；②`standard_geometry` 增加 `biaxial_required=True`，无匹配比例时抛 `NO_STANDARD_MATCH` 而非派生；③`note` 字段出现"派生值"时直接判 FAIL。
- **验收（回放）**：`--replay MO9` 必须报出 `W=94.477 vs 160 (−40.95%)` FAIL。
- **关联**：#17（若 WB 同意合并）；否则新开 `F-DIELINE-01`。

### R-02 结构部件清单由方案派生（P0）
- **契约**：`required` 不得硬编码，须由 `brief.structure.parts` 生成；`part_count` 必须等于声明数；新增 `g3_hinge_continuity`（翻盖与盒身共享边连通）、`g3_tuck_present`（插舌实体存在）。
- **现状**：`required = ["body"]`，因此"部件齐全"恒真。
- **改动点**：`blender_box.py` 输出 `parts[].role` 与 `hinge_edges`；stage_06 按 brief 比对。
- **验收**：`--replay MO9` 报 `part_count 2 < 5` FAIL。

### R-03 extent 双口径 + 废除 12% 容差（P0）
- **契约**：同时输出 `design_extent` 与 `built_extent`，`built = design + 2×D`；容差改 `max(1.0, 2×D)`，绝对值口径。
- **现状**：单一 `extent` 与 `expected` 比对，12% 容差。
- **验收**：MO9 回放输出双口径表，`built_Z=62` 判 **符合**（不再是"偏差 3.33% 勉强通过"），同时 `design_Z` 缺失即 FAIL。

### R-04 门禁判据去体积化（P0，对应 #21）
- **契约**：删除全部 `>200B / >20KB / >50KB`；改内容判据：
  - PNG：尺寸 ≥1600px 且 **非纯色**（主色占比 <90% 且边缘能量 > 阈值）且 sRGB；
  - SVG：`<text>` = 0 且 `entity ≥ N`；
  - PDF：页数 ≥1 且字体全嵌入且图像 300dpi。
- **验收**：注入一张 1×1 白 PNG 撑到 60KB，必须 **FAIL**（注水攻击测试纳入 CI）。

### R-05 G3 接 #17 六条 check + registry + replay（P0）
- **契约**：`g3_anisotropy_le_1_05`、`g3_mesh_watertight`、`g3_normal_consistency`、`g3_artwork_coverage`、`g3_cavity_fit`、`g3_view_distinct` 逐条落 `rule_id/version/表达式`；提供 `--replay <run_dir>`。
- **验收**：#17 验收清单原样通过。

### R-06 渲染与结构同源（P0，最关键）
- **契约**：把 v2 的 Blender 参数化重建（盒身 + 双翻盖 + 插舌 + 纸浆托 + 内容物）固化为 `skills/packview-3d/scripts/build_double_flap.py`，stage_05 调它出图；标准 STP **降级为参考底**，不再三轴缩放出正式交付图。
- **现状**：E4/E7 显示正式渲染路径仍是 STP 缩放空壳。
- **验收**：pipeline 单跑（不介入人工）产出的部件清单/尺寸/内容物与 `hero_*` 对照表一致，差异为 0。

### R-07 `ok` 语义拆分 + 三态强制（P0）
- **契约**：`run_status` 拆 `execution_state` / `gate_state` / `release_state`；`ok` 仅表示执行无异常；无独立证据时 `gate_state` 强制 `NOT_VERIFIED`，**禁止 PASS**。
- **验收**：MO9 回放 `gate_state = NOT_VERIFIED`（当前 `ok=true` 会被同步纠正）。

### R-08 `blocked_items` 进数据模型（P1）
- **契约**：brief 必填项缺失（手机实测尺寸、制造商地址、翻盖叠压量、内托材质）→ 门禁输出 `BLOCKED`，不得 `PASS`；与 #23 T4 的 4 条阻塞项对齐。

### R-09 标准库比例清单（P1）
- **契约**：每个盒型族标注允许 `L/W` 比区间；`double-flap` 当前仅 2.328，需补 1.375 附近的件，或在选型阶段就拒绝用比例不符的标准件。
